CSS Counter Styles

**`CSSCounterStyleRule`** 인터페이스는 @counter-style [at-rule](/ko/docs/Web/CSS/Guides/Syntax/At-rules) 를 나타냅니다.



## 인스턴스 속성

_이 인터페이스는 부모 CSSRule 로부터 상속받은 속성들입니다._

- CSSCounterStyleRule.name
  - : 연관성 있는 규칙의 `name` 으로 정의된 &lt;custom-ident&gt; 의 직렬화가 포함된 문자열 객체입니다.
- CSSCounterStyleRule.system
  - : 연관성 있는 규칙에 의해 정의된 system 설명자의 직렬화가 포함된 문자열 객체입니다. 만일 설명자가 연관된 규칙에 특정되지 않았다면, 이 속성은 빈 문자열을 반환합니다.
- CSSCounterStyleRule.symbols
  - : 연관성 있는 규칙에 의해 정의된 symbols 설명자의 직렬화가 포함된 문자열 객체입니다. 만일 설명자가 연관된 규칙에 특정되지 않았다면, 이 속성은 빈 문자열을 반환합니다.
