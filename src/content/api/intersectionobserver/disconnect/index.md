Intersection Observer API

IntersectionObserver의 **`disconnect()`** 메서드는 감지기의 모든 가시성 변화 주시 대상을 해제합니다.

## 구문

```js
intersectionObserver.disconnect();
```

### 반환 값

`undefined`.
