Console API

**`console.groupEnd()`** 메서드는 [웹 콘솔](https://firefox-source-docs.mozilla.org/devtools-user/web_console/index.html) 로그의 현재 인라인 그룹에서 나옵니다. 자세한 내용과 예제는 console 문서의 [콘솔 그룹 사용하기](/ko/docs/Web/API/console#콘솔_그룹_사용하기)를 참고하세요.



## 구문

```js
groupEnd();
```
