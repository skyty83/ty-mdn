Media Capture and Streams

**`MediaStreamTrack.id`** 읽기 전용 속성은 사용자 에이전트가 생성하는, 트랙의 전역 고유 식별자(GUID)를 담은 DOMString을 반환합니다.

## 구문

```js
const id = track.id;
```
