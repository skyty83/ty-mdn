Geolocation API

**`GeolocationCoordinates.accuracy`** 읽기 전용 속성은 GeolocationCoordinates.latitude와 GeolocationCoordinates.longitude의 오차범위(신뢰수준 95%)를 미터 단위로 표현한, 엄격히 양수로 제한된 `double`입니다.

## 값

GeolocationCoordinates.latitude와 GeolocationCoordinates.longitude의 오차범위(신뢰수준 95%)를 미터로 나타낸 양의 `double`입니다.
