HTML DOM

**`HTMLSpanElement`** 인터페이스는 span 엘리먼트를 나타내며 HTMLElement 인터페이스로부터 파생되었으며 부가적인 프로퍼티나 메소드는 구현되지 않았습니다.



## 프로퍼티

_특정 프로퍼티가 없으며, 부모인 HTMLElement 로부터 프로퍼티를 상속받습니다._

## 메소드

_특정 메소드가 없으며, 부모인 HTMLElement 로부터 메소드를 상속받습니다._
